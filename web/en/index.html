Features — Moodle deadlines, timetable and syllabus in AI

Get what you need from Moodle in conversation, without opening it.

  • Deadlines & submission status

    Every course in one list, with draft and submitted states, including tasks found on course pages.

  • Timetable

    Real start and end times and rooms, including make-up and holiday class days.

  • Syllabus

    Class plan, grading and textbooks — then ask for exam prep right away.

  • Grades, updates & files

    Grades and what's new in each course. Course files are read by the AI.

  • Forum & message search

    Search forums, messages and notifications at once.

  • Quiz review

    Review finished attempts. It never takes quizzes for you.

  • Calendar subscription

    Sync deadlines to Google, Apple or Outlook Calendar.

  • Preview before any change

    Submissions, forum posts, messages and completion marks run only after you confirm a preview.

How to use — connect Claude or ChatGPT in 3 steps

Set up in minutes. Nothing to install.

  1. Sign in to Moodle and connect

    Sign in to Waseda Moodle in your browser, then connect on this site with the bookmarklet or extension. No password.

  2. Add the URL to your AI client

    Add this MCP URL and sign in with OAuth.

    __PUBLIC_URL__/mcp

    Tap to select, then copy.

    • Claude (web, desktop, mobile)
    • ChatGPT
    • Grok
    • Claude Code
    • Cursor
    • VS Code
    • Codex CLI
    • Gemini CLI
    • Other MCP clients

  3. Ask

    Ask in your own words. The AI gathers the answer from Moodle.

Try asking

The AI looks across your courses and returns only what matters.

  • "What's due this week?"
  • "What's my timetable tomorrow?"
  • "How is Marketing graded?"
  • "Only assignments I haven't submitted."
  • "Help me prepare for the exam."

FAQ

Using Waseda Moodle with AI.

Is it free?

Yes, it is free.

Do I need to share my password?

No. You connect from the Moodle session already signed in in your browser, so your password is never entered or stored.

Is this an official Waseda University service?

No. It is an unofficial tool and is not affiliated with Waseda University.

Which AI assistants does it work with?

MCP clients such as Claude (web, desktop, mobile), ChatGPT, Grok, Claude Code, Cursor, VS Code, Codex CLI and Gemini CLI.

Can I delete my data?

Yes, at any time. See the privacy policy for details.
