AI × Waseda Moodle

早稲田 Moodle の締切も時間割も、AI に聞くだけ。

Claude や ChatGPT から、全科目の課題・時間割・シラバス・成績をまとめて確認。パスワード不要、無料。

はじめる 使い方を見る

非公式ツール · 早稲田大学とは関係ありません

できること ─ 締切・時間割・シラバスを AI で

Moodle を開かずに、必要な情報だけを会話で。

  • 締切と提出状況

    全科目の課題を一覧。下書き・提出済みを区別し、コースページ内の課題も拾います。

  • 時間割

    実際の開始・終了時刻と教室。振替授業日・祝日授業日にも対応。

  • シラバス

    授業計画・成績評価・教科書を確認。そのまま試験対策も依頼できます。

  • 成績・更新・資料

    成績と各コースの新着を確認。配布ファイルは AI が読み取ります。

  • フォーラム・メッセージ検索

    フォーラム、メッセージ、通知を横断して検索。

  • 小テストの振り返り

    終了した受験を見直し。受験そのものは代行しません。

  • カレンダー購読

    締切を Google・Apple・Outlook カレンダーに同期。

  • 確認してから操作

    課題提出・投稿・メッセージ送信・完了マークなどは、プレビューを確認した後にのみ実行。

使い方 ─ 3 ステップで Claude・ChatGPT に接続

数分で設定完了。インストールは不要です。

  1. Moodle にログインして接続

    ブラウザで Waseda Moodle にログインし、このサイトでブックマークレットまたは拡張機能から接続。パスワードは入力しません。

  2. AI クライアントに URL を追加

    次の MCP URL を追加し、OAuth でサインインします。

    __PUBLIC_URL__/mcp

    タップで全選択してコピーできます。

    • Claude（Web・デスクトップ・モバイル）
    • ChatGPT
    • Grok
    • Claude Code
    • Cursor
    • VS Code
    • Codex CLI
    • Gemini CLI
    • その他 MCP 対応クライアント

  3. 話しかける

    いつもの言葉で質問するだけ。AI が Moodle から答えを集めます。

例えば、こう聞くだけ

AI が科目をまたいで調べ、要点だけを返します。

  • 「今週の締切を教えて」
  • 「明日の時間割は？」
  • 「マーケティングの成績評価は？」
  • 「未提出の課題だけ」
  • 「試験対策をして」

安心して使える設計

必要最小限のデータだけを、安全に扱います。

  • パスワード不要

    Moodle のパスワードを入力・保存しません。

  • 暗号化して保存

    接続トークンは暗号化して保管します。

  • ファイルは保存しない

    配布ファイルは中継するだけで保存しません。

  • いつでも削除

    データはいつでも削除可能。プライバシーポリシー

よくある質問

早稲田 Moodle × AI の利用について。

無料ですか？

はい、無料です。

パスワードは必要ですか？

不要です。ブラウザでログイン済みの Moodle から接続するため、パスワードを入力・保存することはありません。

早稲田大学の公式サービスですか？

いいえ。非公式ツールで、早稲田大学とは関係ありません。

どの AI で使えますか？

Claude（Web・デスクトップ・モバイル）、ChatGPT、Grok、Claude Code、Cursor、VS Code、Codex CLI、Gemini CLI など、MCP に対応したクライアントで使えます。

データは削除できますか？

はい、いつでも削除できます。詳しくはプライバシーポリシーをご覧ください。
