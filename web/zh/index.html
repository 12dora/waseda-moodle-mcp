功能 ─ 用 AI 查 Moodle 作业截止、课表与教学大纲

无需打开 Moodle，在对话中获取所需信息。

  • 作业截止与提交状态

    汇总全部课程的作业，区分草稿与已提交，并找出课程页面中的任务。

  • 课表

    真实的上下课时间与教室，含调课日和节假日上课日。

  • 教学大纲

    查看授课计划、评分方式和教材，并可直接请 AI 辅助备考。

  • 成绩、动态与资料

    查看成绩和各课程的最新动态，课程文件由 AI 直接读取。

  • 论坛与消息搜索

    跨论坛、消息和通知统一搜索。

  • 测验回顾

    回顾已完成的测验。不会代替你作答。

  • 日历订阅

    将作业截止同步到 Google、Apple 或 Outlook 日历。

  • 先预览，后操作

    提交作业、发帖、发消息、标记完成等操作，均在你确认预览后才执行。

使用方法 ─ 三步接入 Claude 或 ChatGPT

几分钟即可完成，无需安装。

  1. 登录 Moodle 并连接

    在浏览器中登录 Waseda Moodle，然后在本站通过书签工具或浏览器扩展连接。无需输入密码。

  2. 在 AI 客户端添加 URL

    添加以下 MCP URL，并通过 OAuth 登录。

    __PUBLIC_URL__/mcp

    点按即可全选复制。

    • Claude（网页、桌面、移动端）
    • ChatGPT
    • Grok
    • Claude Code
    • Cursor
    • VS Code
    • Codex CLI
    • Gemini CLI
    • 其他 MCP 客户端

  3. 直接提问

    用日常语言提问，AI 会从 Moodle 中整理答案。

比如，这样问

AI 跨课程查询，只返回要点。

  • 「这周有哪些截止的作业？」
  • 「明天的课表是什么？」
  • 「市场营销课怎么评分？」
  • 「只看未提交的作业」
  • 「帮我准备考试」
